ПОТОК — PWA-ПРОЕКТ

Что это:
Установляемая веб-версия исходного приложения «Поток». Исходный интерфейс и логика reader.html сохранены; добавлены PWA manifest, иконки и service worker.

Публикация:
1. Разместите ВСЁ содержимое этой папки на статическом HTTPS-хостинге (например, GitHub Pages, Cloudflare Pages или Netlify).
2. Важно: открывайте сайт по HTTPS. Service Worker не работает с обычным HTTP (кроме localhost).
3. Откройте опубликованный адрес в Chrome на Android.
4. В меню Chrome выберите «Установить приложение» или «Добавить на главный экран».

Автономная работа:
Основные файлы приложения кешируются при установке. Библиотеки JSZip, PDF.js и внешние шрифты кешируются после их первой успешной загрузки онлайн. Поэтому для гарантированной офлайн-работы сначала откройте приложение с интернетом и дождитесь полной загрузки используемых функций.

Хранение:
Книги и прогресс сохраняются в IndexedDB браузера на устройстве. Не очищайте данные сайта/приложения, иначе локальная библиотека может быть удалена.

Ограничения проверки:
Функции импорта EPUB/FB2/DOCX используют JSZip с CDN, PDF — PDF.js с CDN. В этом комплекте сохранена исходная загрузка этих библиотек; офлайн-доступ к ним появится после первой успешной загрузки с CDN. Голоса для озвучивания зависят от голосов, установленных в Android/Chrome.
